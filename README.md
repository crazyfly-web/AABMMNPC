# AI 7 精選組合追蹤器

## Cloudflare Pages 部署

1. 將整個資料夾上傳到 GitHub repository。
2. 在 Cloudflare Pages 建立專案並連接該 repository。
3. Framework preset 選 `None`。
4. Build command 留空。
5. Build output directory 填 `/`。
6. 部署完成後，`functions/api/prices.js` 會成為 `/api/prices`。
